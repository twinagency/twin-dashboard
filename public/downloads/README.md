# Twin OnlyFans Connect

`twin-onlyfans-connect.zip` is built from `jesse98/twin-onlyfans-backend` commit `995d031b326df68f39d488b5bc487549d0626307` with `node scripts/build-twin-connector.mjs OUTPUT.zip`. The shared capture script has one source in that repository.

This is a manually installed desktop Chrome/Edge pilot, not a browser-store listing or mobile login. It submits only after the user confirms the detected account, through the signed-in creator route. Existing encrypted native enrollment verifies provider identity before binding an account; connecting never activates sending. Real OnlyFans provider acceptance is still required.

# Fastt Login Capture

`fastt-login-capture.zip` is `loginExtension/` (without `twin/`) from `twinagency/twin-onlyfans-backend` commit `0af4132ee90bb1886ec64367f1445e337ba5d14d`, built with `git archive --format=zip <commit>:loginExtension`. Its **Copy curl** output is what the admin connection editor's "Paste curl (direct)" box accepts. Manually installed (Load unpacked) desktop Chrome/Edge only.
