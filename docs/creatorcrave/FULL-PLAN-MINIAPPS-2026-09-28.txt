PAYMENTS — TON PAY DOES NOT SOLVE THE 21-DAY HOLD
- TON Pay is real, launched 2026-02-09 by TON Foundation, built for and integrated into mini apps | web
- BUT: telegram's own payments-stars policy still says "payments for digital goods and services must be carried out exclusively in telegram stars," no TON Pay exception exists | web (core.telegram.org/bots/payments-stars)
- TON Pay is for physical goods, services, tips — not digital content unlocks, which is our entire product | web
- confirmed twice: first research pass and a second direct fact-check against telegram's own docs agree | web
- the 21-day hold is Apple/Google's chargeback window, forced onto telegram, not telegram's own choice — telegram cannot shorten it without losing app store compliance | web
- every competitor checked (uhoney, honeychat, luna, gospicy) uses the same pattern: stars inside the mini app (mandatory), CryptoBot or external web/stripe/paddle for players who want faster cash-out, outside the mini app | web
- REAL FIX AVAILABLE: run a parallel web checkout (external link from bot/mini app to a web page) using crypto (NOWPayments, USDT direct) for fans who want to pay off-platform — this is legal because it's not "inside the mini app," same trick every competitor already runs
- do not build any plan around TON Pay replacing stars, treat it as dead end for now, revisit only if telegram/TON explicitly adds a digital-goods exception

- fix is additive: a second front door (real bot per clone) alongside the business connection, not a replacement | code
- only 2 of 18 clones have the mini app storefront Jesse already built — the other 16 are a config job, not new code | code
