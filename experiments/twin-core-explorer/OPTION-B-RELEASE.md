# Mobile Option B release

Implemented the approved unified two-column, three-row capability panel beneath the orb and compact question field. All six systems remain visible while a selected system's capabilities open below. No circular navigation path, ordinal prefixes or category icons. Capability counts come from the existing catalogue, including six for Private Intelligence.

The 56px question field has five rotating practical examples: construction automation, connecting apps, following up leads, handling enquiries and reducing paperwork. Try example explicitly pre-fills the editable field; it does not submit. Suggestions stop while typing, paused, hidden or using reduced motion. Input is never overwritten. Suggested questions route to real existing capabilities. No conversational model or customer-data connection was added.

The clean renderer retains the original 216 particles, 486 links, cyan/white colours, rotation and drift. Exterior diffuse glow, decorative orbital dashes, ambient dust and thick electrical underpaint are removed; white glints and fine electrical flashes stay close to the shell. Desktop layout is not redesigned; it uses the same clean renderer. Header brand, #167CB4 interface accent and bold intro wording are preserved.

Local Chromium verification passed at 320, 350, 375, 390, 414, 430 and 720px: grid and text bounds, 56px field, visible question fit and no horizontal overflow. Six category and 31 feature routes, five example routes, empty/unknown query guardrails, viewport switching with restored desktop DOM, and the workflow approval gate passed. Separate real-time tests passed for main/mini animation, pause/resume, idle question rotation, retaining visitor input and reduced-motion freeze. Deterministic canvas samples at five times had zero painted pixels beyond the tested outer shell envelope. No JS page errors in these tests.

Tests used locally inlined release sources and the Inter fallback, not a physical iPhone or certified font-loading/accessibility audit.
